# NOVA — Creative Portfolio

This is an original HTML and CSS practice project created from scratch for this request.

## Files
- `index.html` — website structure and content
- `style.css` — colours, layout, typography, hover effects and responsive design

## Run locally
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Deploy on Vercel
Import the GitHub repository containing these files. Choose **Other** as the framework preset, leave the build command empty, and set the output directory to `.`. Make sure `index.html` is at the repository root.
